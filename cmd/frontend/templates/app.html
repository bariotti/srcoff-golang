Importar Posição em Lote (Produto/Domínio pelo nome do arquivo)

Selecione um ou vários arquivos de uma vez. O Produto e o Domínio de cada arquivo são identificados pelo padrão de nome cadastrado em Parametrizações (ex: posicao_ndf*.csv → NDF/Posição). Um arquivo que casa com mais de um padrão é importado para cada combinação. A data vem de uma coluna do próprio arquivo.

Produtos
    Domínios
      Padrões de Arquivoassociação → produto / domínio

      Associe um padrão de nome de arquivo a um Produto/Domínio (ex: posicao_ndf*.csv → NDF/Posição). Informe a Coluna da Data Base (a coluna do arquivo que define a data do lote) e o Formato de Data (vale para todas as colunas de data). Os separadores do CSV são opcionais (vazio = automático).

        Pastas de Importação (monitoramento)

        A pasta monitorada é varrida periodicamente; arquivos que casam com um padrão são importados e movidos para a pasta de processados. Arquivos sem padrão permanecem intactos.

        Se vazio ou 0, o monitoramento automático fica desativado (o botão "Escanear agora" continua funcionando).
        Nova Regra
